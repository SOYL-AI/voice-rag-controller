% DRAWING SPEC (the TikZ below implements it; a designer may redraw it from
% this spec in any vector tool, keeping every element):
%  * Full text width (figure*), white background, minimum font 8 pt at print
%    size (\footnotesize in IEEEtran = 8 pt), no colour-only encoding: lanes
%    differ by label and line style as well as colour; readable in greyscale.
%  * Top band, left to right on one time axis: the user's speech; ASR partial
%    ticks x_1 ... x_K; the VAD end-of-turn marker; below each partial a small
%    box for the belief b_k (Eq. 1, recomputed per partial) and for the
%    predicted remaining speech R_k -- "the partial-transcript belief stream".
%  * Lane (a) JOINT (Ours-v2), highlighted (blue fill): ONE decision box that
%    receives BOTH b_k and R_k at every partial and compares "dispatch now"
%    U_k with "wait" (value of the next belief update). Output: a dispatch
%    time that depends on the belief. Annotation: "stopping region is not a
%    product of a belief rule and a timing rule (Prop. 4)".
%  * Lane (b) DECOMPOSED (B9, B9+): two boxes separated by a dashed wall
%    labelled "no shared state": a timing sub-optimiser fixed before the turn
%    (dev constants only, no belief) that fires at a fixed trigger, and a
%    retrieval sub-optimiser that only sees b_k at that trigger and prices
%    L (B9) or the policy-average exposure (B9+).
%  * Lane (c) SPECULATIVE (B10): dispatch at the first query-ready partial,
%    decide USE at end of turn with the final belief b_K; an unused result
%    costs compute only. Annotation: "within lambda_c(1+w) of joint (Prop. 4')".
%  * Right side, shared by all lanes: retrieval -> LLM -> TTS -> first audio,
%    with TTFA (Eq. 4) measured from VAD end of turn to first audio.
% ============================================================================

\caption{Decision structure compared in this paper. A streaming ASR emits
partial transcripts $x_k$; a closed-book pass on each prefix gives the belief
$b_k$, and an end-of-turn predictor gives the remaining speech $\hat R_k$.
(a) The joint controller decides at every partial whether to dispatch now or
wait, using $b_k$ and $\hat R_k$ together. (b) The decomposed controllers fix
the dispatch time without the belief and decide retrieval at that time only.
(c) The speculative controller always prefetches early and decides at the end
of the turn whether to use the result. All controllers share the back end and
are scored by time to first audio (TTFA).}
